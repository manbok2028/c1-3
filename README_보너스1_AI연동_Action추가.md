# 보너스 1 – 생성형 AI 연동 Action 추가

## 1. 과제 개요

기존에 완성한 체납상담 접수 자동화 워크플로우에 `AI by Zapier`를 추가하여, Google Sheets에 새로 접수된 상담내용을 분석하고 다음 텍스트를 자동으로 생성하도록 구현하였다.

- 핵심 상담내용 요약: 2문장 이내
- 고객에게 보낼 접수 안내문: 3문장 이내

AI가 생성한 결과는 긴급사건·일반사건 Gmail 본문에 자동 삽입되며, 이메일 발송 후 Google Sheets의 K열 `처리상태`도 자동으로 변경되도록 구성하였다.

---

## 2. 사용 도구

| 구분 | 사용 도구 | 역할 |
|---|---|---|
| 데이터 입력 | Google Sheets | 체납상담 접수자료 저장 |
| 자동화 | Zapier | 새 행 감지, AI 실행, 조건 분기 및 후속 작업 수행 |
| 생성형 AI | AI by Zapier | 상담요약 및 고객안내문 생성 |
| 조건 분기 | Paths by Zapier | 긴급사건과 일반사건 분류 |
| 알림 발송 | Gmail | 고객에게 접수 결과 이메일 발송 |
| 처리 결과 기록 | Google Sheets | K열 처리상태 자동 업데이트 |

---

## 3. 기존 워크플로우 복제

기존에 정상 작동하던 Zap을 보존하기 위해 복제본을 만들어 보너스 과제를 진행하였다.

- 기존 Zap: `프로젝트1_체납접수_긴급일반분류_Zapier`
- 보너스용 Zap: `BONUS_AI_체납접수자동화_Zapier`

복제본에서만 AI 단계를 추가하고 수정함으로써 기존 완성본이 영향을 받지 않도록 하였다.

---

## 4. 최종 워크플로우 구조

최종 자동화 흐름은 다음과 같다.

1. Google Sheets – `New Spreadsheet Row`
2. AI by Zapier – 상담요약 및 고객안내문 생성
3. Paths by Zapier – 긴급사건·일반사건 분기
4. Gmail – 분류 결과에 맞는 이메일 발송
5. Google Sheets – 접수번호로 대상 행 검색
6. Google Sheets – K열 처리상태 업데이트

각 경로의 세부 구조는 다음과 같다.

### 긴급사건 경로

`긴급도 = 긴급 → Gmail 발송 → 행 검색 → K열 긴급접수 알림완료`

### 일반사건 경로

`긴급도 = 일반 → Gmail 발송 → 행 검색 → K열 일반접수 알림완료`

---

## 5. AI by Zapier Action 추가 과정

Google Sheets Trigger와 Paths 단계 사이의 `+` 버튼을 클릭하고 `AI by Zapier`를 선택하였다. 이 위치에 AI 단계를 배치함으로써 긴급사건과 일반사건 모두 동일한 AI 생성 결과를 사용할 수 있도록 하였다.

AI 단계의 출력 필드는 다음 두 개로 구성하였다.

| 출력 필드 | 생성 내용 |
|---|---|
| `상담요약` | 접수된 상담내용의 핵심 사실을 2문장 이내로 요약 |
| `고객안내문` | 고객에게 보낼 정중한 접수 안내문을 3문장 이내로 작성 |

---

## 6. AI 프롬프트 구성

AI 단계에는 다음과 같은 지시문을 입력하였다.

```text
아래 접수내용을 분석하여 두 가지 결과를 작성하세요.

1. 상담요약: 핵심 사실만 2문장 이내로 정리하세요.
2. 고객안내문: 고객에게 보낼 정중한 접수 안내문을 3문장 이내로 작성하세요.

접수번호: [Google Sheets의 접수번호]
고객명: [Google Sheets의 고객명]
체납기관: [Google Sheets의 체납기관]
체납유형: [Google Sheets의 체납유형]
체납금액구간: [Google Sheets의 체납금액구간]
압류공매여부: [Google Sheets의 압류공매여부]
긴급도: [Google Sheets의 긴급도]
상담내용: [Google Sheets의 상담내용]
```

대괄호 부분은 고정된 테스트 문구를 입력하지 않고, `1. New Spreadsheet Row`에서 전달되는 실제 필드를 동적으로 연결하였다. 따라서 새로운 상담이 접수될 때마다 해당 행의 내용으로 AI 결과가 새롭게 생성된다.

---

## 7. AI 출력 결과 확인

`Generate from prompt`와 Preview 기능을 사용하여 다음 두 결과가 정상적으로 생성되는지 확인하였다.

- `상담요약`: 접수번호, 체납기관, 체납유형, 긴급도 및 상담내용을 바탕으로 핵심 사실을 요약
- `고객안내문`: 고객명과 접수번호를 포함한 정중한 안내문 생성

최종 자동실행 결과는 다음 경로에서도 확인할 수 있다.

`Zap History → BONUS_AI_체납접수자동화_Zapier → Successful 실행기록 → 2. AI by Zapier → Run details → Data out`

---

## 8. Gmail 본문에 AI 결과 연결

긴급사건과 일반사건의 Gmail `Body`에 기존 접수정보와 함께 AI 출력 필드를 삽입하였다.

```text
접수번호: [접수번호]
고객명: [고객명]
체납기관: [체납기관]
체납유형: [체납유형]
긴급도: [긴급도]
상담내용: [상담내용]

AI 상담요약: [AI by Zapier의 상담요약]
AI 고객안내문: [AI by Zapier의 고객안내문]
```

AI 결과는 직접 타이핑하지 않고 `2. AI by Zapier`의 동적 필드에서 `상담요약`과 `고객안내문`을 각각 선택하였다.

일반사건 이메일 제목은 다음과 같이 설정하였다.

```text
[일반 접수] 체납 상담이 접수되었습니다
```

## 9. 테스트 과정에서 발생한 문제와 해결

### 9.1 Gmail 수신자 주소 오류

초기 자동실행에서 Gmail 단계가 다음 오류로 중단되었다.

```text
Recipient address required
```

#### 원인

Gmail의 `To` 항목에 실제 이메일 주소가 아니라 `실제 본인 Gmail 주소`라는 안내용 문구가 전달되어 유효한 수신자로 인식되지 않았다.

#### 해결

- Google Sheets의 `고객이메일` 셀에 실제 Gmail 주소를 입력하였다.
- Gmail `To`에는 `1. New Spreadsheet Row → 고객이메일` 필드를 동적으로 연결하였다.
- 수정한 Zap을 새 버전으로 Publish하였다.

### 9.2 Retest step과 전체 자동실행의 차이

Gmail의 `Retest step`을 실행하면 시험 이메일은 발송되지만, Gmail 아래에 있는 행 검색과 K열 업데이트 단계는 실행되지 않았다.

#### 해결

- `Retest step`은 개별 단계 확인에만 사용하였다.
- 전체 자동실행 검증 시 Google Sheets의 마지막 데이터 바로 아래에 완전히 새로운 행을 추가하였다.
- 기존 행을 수정하거나 Zapier의 Test run 버튼을 누르지 않고 Trigger가 새 행을 감지하도록 기다렸다.

### 9.3 실행기록이 Zap History에 나타나지 않은 문제

Gmail 단계만 Retest한 경우 전체 Zap 실행이 아니므로 Zap History에 새로운 전체 실행기록이 생성되지 않았다.

#### 해결

- 보너스용 Zap이 ON인지 확인하였다.
- 수정사항을 Publish하였다.
- 원본 Zap과 Make 시나리오는 중복 실행 방지를 위해 OFF로 유지하였다.
- 고유한 접수번호가 입력된 새 행으로 다시 자동실행하였다.

---

## 10. 최종 자동실행 테스트

전체 자동실행 확인을 위해 Google Sheets의 마지막 행 아래에 새로운 일반사건 자료를 입력하였다.

| 항목 | 테스트 입력 예시 |
|---|---|
| 접수번호 | `BONUS-AI-NORMAL-04` |
| 접수일시 | 테스트 당시 날짜와 시간 |
| 고객명 | `김가상` |
| 고객이메일 | 실제 테스트 수신용 Gmail 주소 |
| 체납기관 | `지방자치단체` |
| 체납유형 | `지방세 체납` |
| 체납금액구간 | `5백만원 미만` |
| 압류공매여부 | `해당 없음` |
| 긴급도 | `일반` |
| 상담내용 | `AI 일반사건 전체 자동실행 최종 테스트` |
| K열 처리상태 | 빈칸 |

테스트 시 다음 사항을 준수하였다.

- 기존 행을 수정하지 않고 반드시 새 행을 추가하였다.
- K열 처리상태는 자동화가 작성하도록 비워두었다.
- 고객이메일에는 실제 수신 가능한 Gmail 주소를 입력하였다.
- `BONUS_AI_체납접수자동화_Zapier`만 ON으로 유지하였다.
- 원본 Zap과 Make 시나리오는 OFF로 유지하였다.

---

## 11. 최종 실행 결과

전체 자동실행 결과 다음 사항을 확인하였다.

1. Google Sheets의 새 행이 Zapier Trigger에 의해 감지되었다.
2. AI by Zapier가 상담내용을 분석하여 `상담요약`과 `고객안내문`을 생성하였다.
3. 긴급도가 `일반`인 자료가 일반사건 Path로 분류되었다.
4. Gmail 제목 `[일반 접수] 체납 상담이 접수되었습니다`가 실제 수신함에 도착하였다.
5. Gmail 본문에 접수정보와 AI 상담요약·고객안내문이 함께 포함되었다.
6. 대상 행을 접수번호로 검색한 후 K열에 `일반접수 알림완료`가 자동으로 입력되었다.
7. Zap History에서 최종 실행 상태가 `Successful`로 확인되었다.

따라서 생성형 AI Action을 기존 노코드 워크플로우에 연동하여 상담요약과 고객안내문을 자동 생성하고, 이메일 발송 및 처리상태 기록까지 연결하는 보너스 과제를 완료하였다.

## 13. 결론

본 보너스 과제에서는 단순한 조건 분류와 이메일 전송을 넘어, 생성형 AI가 상담내용을 이해하고 요약문과 고객 안내문을 자동으로 작성하도록 워크플로우를 확장하였다.

이를 통해 담당자가 매번 상담내용을 읽고 안내문을 직접 작성해야 하는 시간을 줄이고, 접수내용에 맞는 일관된 안내문을 신속하게 제공할 수 있게 되었다. 또한 Gmail 발송과 Google Sheets 처리상태 업데이트까지 하나의 자동화 흐름으로 연결하여 실제 업무에 활용할 수 있는 구조로 완성하였다.
