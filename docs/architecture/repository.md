# 저장소 운영 규약

## 목적

이 저장소는 1년 동안 미션, 증빙, 운영 개선을 누적합니다. 루트는 탐색 지점만 두고 상세 자료는 역할별 디렉터리에 보관합니다.

## 디렉터리 규칙

- `docs/mission/`: 평가 기준과 적합성 판정
- `docs/architecture/`: 저장소 구조와 유지보수 규칙
- `docs/archive/`: 과거 원문 보고서. 새 문서는 이곳에 직접 작성하지 않음
- `evidence/<scope>/<tool>/`: 변경 불가능한 실행 증빙
- `src/codyssey_c1_3/`: 저장소 품질 자동화 Python 패키지
- `tests/`: Python 표준 `unittest` 테스트

## Python 규칙

- `src` 레이아웃과 PEP 8 이름 규칙을 사용한다.
- 지원 버전은 Python 3.11 이상이다.
- 코어 검증은 표준 라이브러리만 사용한다.
- 공개 함수에는 타입 힌트와 간단한 docstring을 작성한다.
- 파일 시스템 경로는 `pathlib.Path`로 처리한다.
- 새 기능은 테스트와 함께 추가한다.

## 증빙 규칙

- 파일명은 `도구_단계_결과`가 드러나도록 작성한다.
- 민감정보를 마스킹한 이미지 원본만 커밋한다.
- 증빙을 추가하거나 이동하면 `evidence/manifest.toml`도 수정한다.
- 실제 실행을 확인하지 못한 항목은 `pending`으로 유지한다.
- 같은 이미지를 여러 요구사항의 근거로 사용할 수 있지만 근거를 과장하지 않는다.

## Git 규칙

- `main`은 검증을 통과한 상태로 유지한다.
- 작업은 목적이 드러나는 브랜치에서 수행한다.
- 커밋은 한 가지 논리적 변경 단위로 작성한다.
- PR 본문에 변경 이유, 영향, 검증 결과, 남은 갭을 기록한다.
