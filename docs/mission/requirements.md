# 미션 요구사항 기준선

## 프로젝트 1 · 자동화 도구 비교 구현

- 동일한 워크플로우를 서로 다른 도구 2개 이상으로 구현한다.
- 도구별 구성 화면과 실행 결과를 제출한다.
- Trigger 1개 이상, Action 2개 이상, 조건 분기 1개 이상을 포함한다.
- 모든 분기 경로가 실제로 한 번 이상 실행되어야 한다.
- UI/UX, 설정 난이도, 연동 범위, 무료 플랜, 실행 로그 등 최소 5개 항목을 비교한다.
- 도구별 장단점과 적합한 상황을 설명한다.

## 프로젝트 2 · 자유 주제 자동화

- 반복 업무 하나를 정의한다.
- 도구 하나를 선정하고 이유를 기록한다.
- Trigger에 의해 자동 실행되는 실제 워크플로우를 구현한다.
- 설계 문서 또는 다이어그램, 구현 화면, 실행 결과를 제출한다.

## 공통 및 보안

- 설계만으로는 완료로 인정하지 않는다.
- 이메일, 토큰, API 키 등 민감정보를 캡처에서 마스킹한다.
- 실행 실패와 복구 경로는 선택 보너스이지만 운영 품질 기준으로 유지한다.
